## Projects

### [EVALIS](https://elavis.vercel.app) — EV Brand Platform
Solo-built frontend-only EV platform combining a cinematic marketing site, customer ownership dashboard, and admin back-office in a single React 19 + TypeScript application. Built the full data model, routing architecture, and a localStorage-based persistence layer with cross-component sync to simulate a real backend. Live-map charging station tracking, automated charge-scheduling engine, shop/checkout simulation, and full English/Turkish localization — all styled from scratch with Tailwind CSS v4, no UI library.

### [ConneXion AI](https://connexion-ai.vercel.app) — AI Customer Service Platform
Collaborated on a multi-tenant AI customer support platform. Led the design and frontend implementation of role-based dashboards for Platform Admin, Workspace Admin, Manager, and Support Agent roles — responsive, reusable, and scalable enterprise SaaS interfaces built with React and Tailwind CSS.

### [ParkinScan](https://parkinscan.netlify.app) — AI-Powered Parkinson's Screening
Team graduation project. Led the end-to-end frontend implementation: complete UI, ML model integration, real-time facial tracking with MediaPipe FaceMesh, client-side PDF report generation with jsPDF, and full deployment on Netlify, Render, and Supabase.
